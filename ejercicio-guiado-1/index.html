clasificación de modelos Cloud
Ejercicio Guiado 1 · Java

Descripción de la actividad

La aplicación Cloud Models Classifier recibe una descripción de un servicio Cloud y presenta su clasificación como IaaS, PaaS, SaaS o FaaS.

Las evidencias muestran una interfaz gráfica, el nivel de confianza, el puntaje obtenido y la ejecución del programa desde PowerShell.

01

OBJETIVO

Clasificar descripciones de servicios Cloud y mostrar el modelo identificado junto con su nivel de confianza y puntaje.

Evidencia 01

IaaS

La primera prueba describe máquinas virtuales, almacenamiento y redes configurables para instalar un sistema operativo propio.

La interfaz presenta IaaS, confianza Muy Alta y 12 puntos.

Evidencia 02

PaaS

La descripción plantea desplegar una aplicación web sin administrar directamente servidores ni sistemas operativos.

El resultado visible es PaaS, con confianza Muy Alta y 21 puntos.

Evidencia 03

SaaS

La prueba describe una aplicación de correo electrónico utilizada desde el navegador mediante una suscripción mensual.

La aplicación la clasifica como SaaS, con confianza Muy Alta y 12 puntos.

Evidencia 04

FaaS

La entrada solicita ejecutar automáticamente una función cuando un usuario suba una imagen al almacenamiento Cloud.

La interfaz muestra FaaS, confianza Muy Alta y 12 puntos.

Evidencia 05

OTRA PRUEBA IaaS

La quinta captura utiliza una descripción sobre servidores virtuales, almacenamiento, red propia y elección del sistema operativo.

El resultado es IaaS, esta vez con confianza Media y 5 puntos.

Evidencia 06

POWERSHELL

La captura muestra las carpetas bin, resources y src del proyecto.

También se observa la compilación con javac -encoding UTF-8 -d bin y la ejecución con java -cp bin. La entrada escrita en consola devuelve Modelo identificado: IaaS.

✦ ♡ ✦

CONCLUSIÓN

Las evidencias registran clasificaciones para los cuatro modelos Cloud desde la interfaz gráfica y una ejecución adicional desde PowerShell.

También muestran que el programa informa el nivel de confianza y el puntaje de cada clasificación.
