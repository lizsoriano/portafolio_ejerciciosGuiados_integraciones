clasificación de modelos Cloud
Parcial 01 · Actividad 1

Presentación

En esta actividad desarrollé un clasificador de modelos de servicios Cloud utilizando Python.

El programa analiza una descripción escrita por el usuario e identifica si corresponde a IaaS, PaaS, SaaS o FaaS.

El proyecto cuenta con interfaz gráfica, interfaz de línea de comandos y pruebas automáticas.

interfaz del proyecto ↘
01

ARQUITECTURA

El proyecto fue dividido en diferentes archivos para separar correctamente las responsabilidades.

classifier.py

Contiene la lógica principal del clasificador, procesamiento de texto, reglas, puntuaciones y detección del modelo Cloud.

gui.py

Contiene la interfaz gráfica realizada con Tkinter y utiliza la función classify_text().

cli.py

Implementa una interfaz de línea de comandos utilizando argparse.

test_classifier.py

Contiene las pruebas automáticas del clasificador utilizando unittest.

✦

Objetivo

Mantener la lógica del clasificador independiente de las interfaces.

De esta forma la GUI y la CLI reutilizan exactamente la misma función de clasificación.

♡
02

PROCESAMIENTO NLP

Antes de clasificar el servicio Cloud, el texto pasa por diferentes etapas de procesamiento.

01Minúsculas
02Eliminar acentos
03Limpiar puntuación
04Tokenización
05Stopwords
06Stemming
07Conceptos
08Reglas Regex
09Puntuación

Todo el procesamiento fue realizado sin utilizar librerías externas como NLTK o spaCy.

Evidencia 01

CLI

La interfaz de línea de comandos utiliza argparse para recibir el nombre, apellido y descripción del servicio Cloud.

La descripción “maquinas virtuales almacenamiento redes” fue clasificada como IaaS con puntuación de 15.

Evidencia 02

PRUEBAS

Se implementaron seis pruebas automáticas con unittest para IaaS, PaaS, SaaS, FaaS, texto vacío y un caso sin suficiente evidencia.

Las seis pruebas terminaron correctamente con resultado OK.

Evidencia 03

GUI

La interfaz gráfica fue desarrollada con Tkinter. Permite capturar nombre, apellido y descripción del servicio Cloud.

Después de clasificar muestra el modelo identificado, puntuación y conceptos encontrados.

Evidencia 04

VALIDACIÓN DE SINTAXIS

Se utilizó py_compile para comprobar que classifier.py · gui.py · cli.py · test_classifier.py tuvieran sintaxis válida.

El comando terminó sin mostrar errores.

CONCLUSIÓN

La actividad permitió desarrollar un clasificador modular capaz de identificar diferentes modelos de servicios Cloud.

La separación entre la lógica, la interfaz gráfica y la CLI facilita el mantenimiento y permite reutilizar el mismo clasificador desde diferentes interfaces.
